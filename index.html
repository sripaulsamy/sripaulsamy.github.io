Case

Inside a project: the teaming evaluation

As a teaching assistant, Sri took over a slow, manual job: collecting and consolidating peer evaluations for team projects. She built a reusable system instead: a web form for students, backed by a Google Sheet that scores, ranks and compiles every response automatically. Each semester it is reset by swapping in a new roster and settings, with no code changes. It has run for the UTDeakin COIL Summer 2026 program and for ACCT 6341 in Fall 2026.

In the evaluation, each student awards bonus "checks" of set values to teammates, adds a one-word descriptor and a written justification. The sheet then builds a tab for every team, totals what each member received, ranks them, converts rank to a peer score, compiles the remarks, and lists who hasn't submitted.

  1. Roster in. The instructor pastes the class roster with team assignments.
  2. Students submit. The web form shows each student only their own teammates and the allowed check values, and emails a confirmation.
  3. Responses log. Every submission is time-stamped with a submission ID; resubmissions are tracked.
  4. Team tabs build themselves. Totals received, number of evaluators, rank, peer score, descriptors, compiled and anonymous remarks.
  5. Follow-up is easy. A "Not submitted" tab lists who still owes an evaluation.
  6. Next semester. New roster and settings; the code stays the same.
